# 项目阅读指南

| 关注方向 | 建议阅读顺序 | 面试可讨论的实现 |
| --- | --- | --- |
| 软件开发 / 后端 | iCure 本机版 → Qt 团队原版 → SQL 实验 | 角色权限、事务、预约冲突、附件访问、数据迁移与回归测试 |
| AI 应用 / 算法工程 | TextCNN → YOLO → MiniChat | 训练/验证隔离、词表与权重一致、推理参数、结果导出和模型依赖 |
| 系统 / 并行计算 | KMeans CPU/CUDA → RISC-V → Java | 数据格式、越界与空簇、并行比较条件、数据通路与整数精度 |
| 图形学 / 科研 | 网格渲染 → JNeRF 复现资料 → 毕业设计 | 可微渲染接口、场景数据、上游复现步骤与模型适配边界 |

求职时优先展示能解释、能运行并能说明个人职责的项目。iCure 是团队项目。用户提供的项目 PPT 第 8 页明确涂恺倪为 TL（团队领袖），负责医生端系统、聊天机器人和系统翻译功能；医生端与翻译入口可在 Qt 源码中对应，原版聊天机器人完整实现尚未确认，不将整套系统写成个人独立开发。毕业设计当前缺少研究模型与训练主体，先恢复缺失实现和可信实验日志，再把模型指标列入简历。

代码仓库中的本次补全、重构和测试反映后续维护能力，不应写成在原课程提交时已经完成。涉及上游复现时，说明引用的框架和自己实际修改的内容。
